# Kindergarten "Sonechko" Landing Page ☀️

A modern, fully responsive landing page for a private kindergarten, built with clean HTML5, CSS3 (Flexbox/Grid), and JavaScript (ES6+). Designed to provide a warm, welcoming experience for parents while offering seamless navigation, interactive sliders, and quick communication channels.

## Features
- **Fully Responsive Layout:** Optimized for desktops, tablets, and mobile phones.
- **Interactive Elements:** Smooth mobile menu toggling, testimonials/gallery sliders (Swiper.js), and interactive UI components.
- **Performance Focused:** Lightweight assets, WebP image optimization, and clean modular styling.
- **Social Proof Integration:** Branded badges and direct links for social networks (Instagram, Telegram, Viber).
- **Call to Action:** Clean consultation request and feedback form.

## Tech Stack
- **HTML5** (Semantic markup)
- **CSS3** (Custom properties, Flexbox, Grid, Media Queries)
- **JavaScript (ES6+)** (DOM manipulation, interactive UI logic)
- **Swiper.js** (Touch-friendly carousels)

## Getting Started

   ```bash
   git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
   ```
2. Open the project directory in your code editor (e.g., WebStorm, VS Code).
3. Open `index.html` in your browser or run it via a local development server (Live Server).

# Лендинг частного детского сада "Сонечко" ☀️

Современный, полностью адаптивный лендинг для частного детского сада, созданный с использованием чистого HTML5, CSS3 (Flexbox/Grid) и JavaScript (ES6+). Сайт разработан для создания теплого, доверительного впечатления у родителей и обеспечивает удобную навигацию, интерактивные слайдеры и быстрые каналы связи.

## Особенности
- **Адаптивный дизайн:** Оптимизирован для ПК, планшетов и мобильных устройств.
- **Интерактивные элементы:** Мобильное меню, слайдеры галереи и отзывов (Swiper.js), интерактивные компоненты интерфейса.
- **Оптимизация производительности:** Легкие ресурсы, поддержка формата WebP, чистый модульный CSS.
- **Интеграция соцсетей:** Стильные фирменные плашки и ссылки на Instagram, Telegram и Viber.
- **Форма обратной связи:** Удобная отправка заявок для родителей.

## Стек технологий
- **HTML5** (Семантическая верстка)
- **CSS3** (Переменные, Flexbox, Grid, Медиазапросы)
- **JavaScript (ES6+)** (Интерактивная логика UI)
- **Swiper.js** (Сенсорные карусели)
